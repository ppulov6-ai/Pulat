# Отчёт по домашнему заданию

Я разработал персональный AI-анализатор конкурентов в нише оборудования и услуг ГРП.

Для анализа выбрал четыре компании: Halliburton, Liberty Energy, Jereh и SLB. По официальным материалам подготовил четыре PDF-карточки и сохранил их в папку `data/`.

В проекте настроил FastAPI, анализ текста и изображений, отраслевые JSON-поля `design_score`, `frac_relevance_score`, `industrial_credibility_score` и `digitalization_potential`. Добавил Selenium-парсер четырёх разрешённых сайтов, локальную историю на 10 запросов, веб-интерфейс и PyQt6 desktop-приложение.

Ключи в проект не добавлял: для них предусмотрен локальный `.env`, а сам файл исключён через `.gitignore`. Проект работает только на локальном адресе и не разрешает парсеру открывать посторонние или локальные домены.

Код, схемы, безопасность URL, история и API проверены: два полных прогона по 18 тестов завершились успешно, отдельный HTTP-прогон подтвердил главную страницу, OpenAPI, безопасный отказ без ключа и блокировку чужого домена. Реальный ответ ProxyAPI требует личного ключа. Файл `competitionmonitor.exe` собирается командой `python build.py` и должен проверяться в Windows, потому что PyInstaller не собирает Windows-приложения из Linux. В текущей Linux-среде также нет Chrome и системной `libEGL`, поэтому реальный прогон Selenium и окна PyQt здесь не выдаю за выполненный; для них подготовлены рабочий код, зависимости и инструкция запуска в Windows.

Проект опубликован в отдельной папке публичного GitHub-репозитория. Файл `.env`, API-ключи и временные данные в репозиторий не загружены.
