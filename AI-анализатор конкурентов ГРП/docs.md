# Документация API

Базовый адрес: `http://127.0.0.1:8000`.

## POST /analyze_text

JSON-запрос:

```json
{"text": "Описание услуг или технологии конкурента длиной от 20 символов", "company_name": "Название"}
```

Ответ содержит позиционирование, сильные и слабые стороны, технологии, риски, рекомендации, `frac_relevance_score` и `digitalization_potential`.

## POST /analyze_image

`multipart/form-data`:

- `file`: JPEG, PNG или WEBP, максимум 10 МБ;
- `company_name`: необязательная подпись.

Ответ содержит `design_score`, `industrial_credibility_score`, `frac_relevance_score`, `digitalization_potential`, маркетинговые инсайты, визуальные слабости и рекомендации.

## POST /parse_demo

Безопасный вариант по ключу:

```json
{"competitor": "halliburton"}
```

Допустимые значения: `halliburton`, `liberty`, `jereh`, `slb`.

Можно передать `url`, но только HTTPS-ссылку разрешённого домена из `backend/config.py`. Selenium открывает страницу, ждёт DOM, извлекает текст, сохраняет скриншот локально, отправляет текст модели и записывает результат в историю.

## GET /history

Возвращает последние 10 успешных анализов.

## DELETE /history

Очищает локальную историю. Успешный ответ: HTTP 204.

## GET /health

Проверяет backend. Поле `api_configured` показывает только наличие настройки ключа, но не раскрывает его.

## Ошибки

- `400`: некорректный файл или запрещённый URL;
- `413`: изображение больше 10 МБ;
- `415`: неподдерживаемый тип изображения;
- `422`: запрос не соответствует схеме;
- `502`: внешний сервис или Selenium не выполнил запрос;
- `503`: `PROXY_API_KEY` не настроен.

## Мультимодальный пайплайн

1. Пользователь передаёт текст, изображение или выбранный сайт.
2. Backend проверяет формат и ограничения безопасности.
3. ProxyAPI вызывает мультимодальную модель.
4. Pydantic проверяет структуру и диапазон оценок 0-10.
5. Успешный результат атомарно сохраняется в локальную историю.
