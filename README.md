# Pulat — прикладные ИИ-инструменты

Репозиторий объединяет мои проекты по RAG, LLM-интеграциям и цифровым инструментам для нефтесервиса.

## Проекты

### AI-анализатор конкурентов ГРП

Статус: **в разработке** — исходный код находится в [pull request](https://github.com/ppulov6-ai/Pulat/pull/1).

Задача — ускорить анализ компаний, оборудования и цифровых решений в сфере ГРП.

Функциональные блоки:

- анализ текста и изображений через LLM;
- отраслевой JSON-результат: позиционирование, технологии, риски и рекомендации;
- безопасный парсинг только разрешённых сайтов;
- FastAPI API, веб-интерфейс и desktop-приложение;
- локальная история анализов и автоматические тесты.

Стек: `Python`, `FastAPI`, `Selenium`, `PyQt6`, `OpenAI-compatible API`, `PyInstaller`.

Запуск и требования описаны в README проекта внутри pull request. API-ключи в репозиторий не добавляются: используется локальный `.env`.

### Финальный RAG-ассистент

Папка: [Финальный_RAG_ассистент](./Финальный_RAG_ассистент)

Ассистент отвечает по подключённой базе знаний. Проект показывает полный RAG-цикл:

- загрузка и очистка документов;
- разбиение текста на фрагменты;
- семантический поиск релевантного контекста;
- генерация ответа LLM;
- тестирование ответов на факты, перефразирование и вопрос без ответа.

### Кэширование RAG

Папка: [Кэширование_RAG](./Кэширование_RAG)

Практика по ускорению повторных запросов к RAG-ассистенту и контролю краткосрочного контекста диалога.

## Как запустить

Каждый проект имеет собственные зависимости и инструкцию в своей папке. Общая последовательность:

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Перед запуском проверьте README нужного проекта: состав зависимостей и точка входа могут отличаться.

## Безопасность

Секреты, API-ключи, кэши и временные данные не хранятся в GitHub. Для конфигурации используются локальные файлы окружения и шаблоны без ключей.
