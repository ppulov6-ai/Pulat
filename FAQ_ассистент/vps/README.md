# Запуск портфолио на VPS с Caddy
Из папки FAQ_ассистент запустите `docker compose -p pulat-portfolio -f vps/compose.yaml up -d --build`. Проверьте `curl -fsS http://127.0.0.1:18241/health`. Порт доступен с самого сервера. Другой свободный порт можно задать через PORTFOLIO_PORT.

Создайте DNS-запись выбранного поддомена на адрес VPS. В отдельном блоке действующего Caddyfile для этого поддомена укажите `reverse_proxy 127.0.0.1:18241` (для Caddy на хосте). Проверьте конфигурацию командой caddy validate и перезагрузите конфигурацию действующей службы Caddy. Проверьте HTTPS, отправку сообщения через /#chat и повторный запрос на /logging.

Журнал создаётся в SQLite в постоянном томе portfolio-data. История с прежнего хостинга автоматически не импортируется. Для запуска без Docker нужны Python 3 и Node.js 24: выполните python3 build-site.py и запустите node vps/server.mjs с DB_PATH, указывающим на доступный для записи файл. По умолчанию этот процесс слушает только 127.0.0.1.
