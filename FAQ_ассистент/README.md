# FAQ-ассистент для заказчиков

[Открыть опубликованный чат](https://pulat-brand-dz-1911.ppulov6.chatgpt.site/#chat). На сайте представлены работы Пулата Сафарова и контакты для обсуждения заказа.

Виджет отправляет запрос в `POST /chat`. Сервер подбирает ответ по базе кейсов и примерам коммерческих диалогов. Данные для компактного поиска получены из дообученной ruGPT. Веса полной генеративной модели доступны в артефактах запуска обучения. При слабом совпадении клиент получает ссылку для прямой связи.

В `src/prices.json` приведены четыре сопоставимых публичных заказа на Freelancehunt. В диалогах используются максимальные видимые предложения исполнителей для выбранного заказа и исходной валюты. Это архивные ориентиры. Сумму конкретного заказа Пулат согласует с клиентом. Формулировки и суммы ответов находятся в `src/topics.json`.

Для сборки и проверки из этой папки запустите `python3 build-site.py`, затем `node test-faq.mjs` (Node.js 22+). Файл `dist/server/index.js` экспортирует обработчик Worker. Для страницы журнала требуется привязка D1 и миграция в `drizzle`. Чат доступен без ключей внешних API.
