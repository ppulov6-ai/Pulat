## 1. Подготовка

Проект распакован в отдельную папку, создано и активировано окружение `venv`, зависимости установлены; `pip check` не обнаружил конфликтов. В архиве шаблон назывался `env.example`: добавлена копия `.env.example`, подготовлен `.env`. Версии зафиксированы в `requirements-lock.txt`.

Старые `cache.json` и ChromaDB из архива исключены из эксперимента. Индекс заново построен по трём исходным документам: Python, машинное обучение и векторные базы данных. Всего 9 фрагментов. Тексты также доступны в [data](data).


### Полученные ответы

**Привет, что ты умеешь?**

Привет! Я могу создавать высококачественные векторные представления текста, что полезно для семантического поиска. Также я умею использовать RAG (Retrieval-Augmented Generation) для улучшения качества ответов, дополняя их внешними знаниями из базы данных. Кроме того, я могу работать с Python - языком программирования общего назначения, который известен своей простотой и читаемостью кода.

**Что такое RAG?**

RAG (Retrieval-Augmented Generation) - это техника, которая улучшает качество ответов языковых моделей. Она дополняет эти модели внешними знаниями из базы данных, что позволяет им давать более точные и актуальные ответы, основанные на конкретных документах.

**Что такое ИИ?**

Искусственный интеллект (ИИ) - это область компьютерных наук, которая стремится создавать системы, способные выполнять задачи, обычно требующие человеческого уровня интеллекта. В контексте базы знаний, мы говорим о машинном обучении как одной из его областей.

Машинное обучение - это методы и алгоритмы искусственного интеллекта, которые позволяют компьютерам выполнять задачи без явного программирования. Они анализируют данные и вырабатывают модели для предсказания или принятия решений на основе этих данных.

## 4. TOP_K=3 и TOP_K=7

Один вопрос «Что такое векторная база?» выполнен при `TOP_K=3`, затем `.env` изменён на `TOP_K=7` и `python main.py` запущен заново. Модель, температура и документы остались прежними. В обоих случаях был промах кэша.

| TOP_K | Получено фрагментов | Время, с | Кэш найден? |
|---:|---:|---:|:---:|
| 3 | 3 | 12.903573 | Нет |
| 7 | 7 | 14.020031 | Нет |

**Ответ при TOP_K=3:**

Векторная база данных - это специализированные системы хранения данных, оптимизированных для хранения и поиска векторных эмбеддингов. Эмбеддинги представляют данные (текст, изображение, аудио) в многомерном пространстве, где семантически похожие объекты располагаются близко друг к другу.

**Ответ при TOP_K=7:**

Векторная база данных - это специализированные системы хранения данных, оптимизированных для хранения и поиска векторных эмбеддингов. Эмбеддинги представляют собой векторные представления данных (текста, изображений, аудио) в многомерном пространстве, где семантически похожие объекты располагаются близко друг к другу.

Смысл ответов практически одинаков: определение векторной базы, представление данных эмбеддингами и близость семантически похожих объектов. Дополнительные четыре фрагмента не дали заметного прироста полезных деталей; время увеличилось. Для этого вопроса оснований предпочесть 7 вместо 3 не обнаружено.

Журналы: [TOP_K=3](results/pass_1/02_top_k_3.log), [TOP_K=7](results/pass_1/03_top_k_7.log).

### Фильтр метаданных Python

В `embeddings.py` добавлен аргумент `source`; поиск передаёт в Chroma `where={"source": "Python"}`. У исходного документа «Python Основы» поле `source` приведено к `Python`, исходное название сохранено в `title`. Фильтрация выполняется самой базой до выдачи результатов. [Документация Chroma](https://docs.trychroma.com/docs/querying-collections/metadata-filtering).

```ini
TOP_K=7
SOURCE_FILTER=Python
```

После перезапуска получены только два фрагмента источника Python. Их меньше семи, поскольку фильтр ограничивает набор документов.

В предоставленном контексте нет информации о векторной базе. Я не могу ответить на этот вопрос на основе данного контекста.

**Что такое Python и где он применяется?**

Python - это высокоуровневый язык программирования общего назначения, созданный Гвидо ван Россумом и выпущенный в 1991 году. Он известен своей простотой и читаемостью кода.

Python применяется во многих областях:
- Веб-разработка
- Анализ данных
- Машино обучение
- Автоматизация
- Научные вычисления

На вопрос о векторной базе модель сообщила об отсутствии данных в отфильтрованном контексте. На вопрос о Python ответила по выбранному источнику. [Журнал фильтра](results/pass_1/04_filter_python.log).

## Повторный запуск

Проверенное окружение: Linux, Python 3.12, CPU, до 8 потоков модели. Веса занимают около 2.6 ГБ и не включены в репозиторий; загрузчик сверяет их размер и SHA256. Источники и ревизии использованных файлов: [model_manifest.json](model_manifest.json).

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements-local.txt --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
cp env.local.example .env
python download_models.py
```

В первом терминале запустить локальный сервер:

```bash
python -m llama_cpp.server --model models/qwen/qwen2.5-3b-instruct-q4_k_m.gguf --model_alias qwen2.5-3b-instruct --host 127.0.0.1 --port 8765 --n_ctx 8192 --n_threads 8 --n_threads_batch 8 --n_batch 512 --chat_format chatml --verbose false
```

Во втором терминале с тем же окружением:

```bash
python main.py
```

Для нового эксперимента сохранить приложенные результаты, убрать итоговый `cache.json` из рабочей папки и начать с `TOP_K=3`. Для автоматического повторения в новой рабочей копии использовать `python run_experiments.py`: он очищает рабочий кэш и ChromaDB между двумя проходами, но откажется перезаписывать существующую папку `results/pass_1`.

Для OpenAI использовать `.env.example`, задать свой ключ только локально и установить `BACKEND=openai`. Внешний API и Windows в этой работе не проверялись. При смене модели эмбеддингов нужно пересоздать ChromaDB.

**Вывод:** кэш заметно сокращает повторную обработку одинаковых вопросов. Увеличение TOP_K само по себе не гарантирует более подробный ответ. Фильтр метаданных позволяет ограничить поиск нужным источником.
