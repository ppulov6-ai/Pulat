## Как проверить в браузере

Нажмите «Что такое RAG?» дважды. Сначала сервер извлечёт фрагмент из документа «Машинное обучение и AI», затем прочитает сохранённый ответ. Запросите телефон поддержки: в учебных материалах его нет. Обновите страницу, сравните статусы и скачайте CSV. Журнал привязан к анонимной сессии браузера.

| Контрольная запись 19.11.2026 | Статус | Из кэша | Обработка |
|---|---|---:|---:|
| №1. Что такое RAG? | ok | нет | 42 мс |
| №2. Что такое RAG? | ok | да | 48 мс |
| №3. Какой телефон службы поддержки проекта? | no_answer | нет | 51 мс |

Все три записи остались после обновления страницы. Время включает запрос к хранилищу и подготовку ответа до вставки записи. Эти три замера показывают работу журнала, по ним нельзя оценить ускорение от кэша.

## Полная версия на Python

Установите окружение по [инструкции проекта](README.md) и запустите обычный `python main.py`. При инициализации создаётся `results/logs.db`; другой путь можно задать через `LOG_DB`. На сервере размещайте базу на постоянном диске. В интерактивном режиме `/stats` показывает количество обращений и попаданий в кэш, `/csv` сохраняет CSV рядом с базой.

В `answer_question` журналируются и вызовы модели, и ответы из кэша. Запись содержит дату и время UTC, вопрос, ответ, источник, признак кэша и длительность обработки. Если операция завершилась исключением, в SQLite остаётся тип ошибки с источником console.error. Существующий журнал JSONL сохранён. SQLite и CSV содержат тексты локальных запросов и предназначены для владельца проекта.

Класс DatabaseLogger адаптирован из [кода преподавателя](https://github.com/MrGAN12009/5-7-new_version/blob/main/db_logger.py). Интеграционный тест с подменой генератора прошёл три ветки: ответ, кэш и исключение. После повторного открытия базы сохранились три записи, экспорт вернул три строки. Генерация Qwen в этот тест не входила.

## Серверная версия

На действующем сайте размещён обработчик Cloudflare Workers с постоянным хранилищем D1 (SQLite). Для демонстрации используются четыре фиксированных вопроса и фрагменты оригинальных документов из embeddings.py. Поиск извлекает фрагмент по опорной фразе, успешный ответ кэшируется для сессии. Эта версия работает без токенов и загрузки весов Qwen. Исходный Python-проект использует ChromaDB и выбранную модель как раньше.

В CSV доступны последние 100 записей текущей сессии. Идентификатор сессии в экспорт не попадает. Сервер удаляет записи старше семи дней при следующей записи в журнал.
