# Короткие ответы на заявки об автоматизации

Дообучение стиля первичного ответа заказчику. Цель: коротко предложить действие и задать один вопрос по задаче. Учебные диалоги синтетические. В train.json 48 пар, в test.json шесть отдельных переформулированных обращений. Темы пересекаются с обучением, дословных совпадений запросов нет.

## Результат обучения

На шести контрольных обращениях базовая модель выполнила критерий формы 0 раз, модель с адаптером — 6 раз. Веса адаптера перезагружены перед проверкой. Обучались 2 359 296 из 127 590 912 параметров. Средние потери на обучающих пакетах снизились с 3,019 до 0,116 за пять эпох.

**Удачный ответ.** На вопрос о записи посетителей на массаж модель ответила: «Соберу запись посетителей на массаж в одном месте. Где сейчас ведёте расписание?»

**Ошибка по смыслу.** На запрос о боте для заказа кухонь модель ответила: «Соберу кухни в одном месте. Где сейчас отмечаете свободные часы?» Формат выдержан, но перепутаны задача и уточнение. Данные содержат всего 12 различных целевых ответов. Эксперимент подтверждает усвоение формата на этих примерах; для общения с заказчиками нужна отдельная проверка уместности.

## Методика

Основа — [код урока](https://github.com/MrGAN12009/case2_code). Из него взяты формат instruction/output, разметка промпта и выбор модулей GPT-2 для адаптеров. Для русского языка выбрана ruGPT-3 Small. В этой реализации ошибка обучения считается только по ответу. Ранг 16, alpha 32, dropout 0,05; пять эпох, batch 4, AdamW, шаг 0,0005. Базовые веса заморожены.

Запуск в каталоге проекта с Python 3.11:
~~~bash
python -m pip install torch==2.6.0 --index-url https://download.pytorch.org/whl/cpu
python -m pip install -r requirements.txt
python run.py
python run.py --chat
~~~

Обучение сохраняет адаптер в result/adapter, перезагружает его и генерирует ответы с одинаковыми настройками до и после. В result/report.json находятся исходные ответы, контрольные ответы и потери по эпохам. Критерий формы: до 25 слов и один вопросительный знак в конце. Уместность и смысл проверяются чтением самих ответов.
