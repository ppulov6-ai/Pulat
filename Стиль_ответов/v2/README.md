# Какой вопрос задать заказчику

Продолжение опыта с ruGPT-3 Small. Задача: по описанию заявки определить следующий недостающий параметр. Одна и та же отрасль представлена на трёх стадиях заполнения. Например, для расчёта кухни сначала нужен план помещения, затем материал фасадов, а после сбора этих данных можно уточнить адресата расчёта.

**Данные.** 168 синтетических русскоязычных пар, 7 отраслей, 21 ситуация. На каждую ситуацию приходится восемь вариантов входного текста и один целевой ответ. Это контролируемый учебный набор. Открытые формы и справочные страницы использованы для выбора полей и этапов. Диалоги написаны для эксперимента, персональных данных и частных переписок в них нет.

| Сценарий | Публичный ориентир |
|---|---|
| Кухни на заказ | [Мебельная фабрика «Мария», замер помещения](https://www.marya.ru/services/zamer/) |
| Ремонт техники | [Заявка на ремонт Bosch и Siemens](https://www.bsh-russia.ru/servis/zakaz-na-remont) |
| Запись к специалисту | [YCLIENTS, шаги онлайн-записи](https://support.yclients.ru/178--shagi-individualnoj-onlajn-zapisi) |
| Доставка цветов | [Flowwow, оформление заказа](https://flowwow.com/faq-client/placing-an-order/) |
| Прокат | [Московский транспорт, условия проката](https://transport.mos.ru/mostrans/for_journs/docs/261) |
| Подбор персонала | [Хантфлоу, заявка на вакансию](https://huntflow.ru/help/knowledge-base/application-new/) |
| Запись на обучение | [Tilda, регистрация через Timepad](https://help-ru.tilda.cc/timepad) |

**Проверка.** Контрольные 21 переформулировка и ожидаемые темы уточнений записаны в test.tsv до обучения. Базовая модель и настройки LoRA те же, что в первом опыте. Обе версии получают одинаковые вопросы без подсказок и генерируют ответы с greedy-декодированием. Автоматический балл требует единственный вопросительный знак и ожидаемый корень слова в финальном вопросе. Такой балл проверяет тему и не заменяет чтение ответов. Домены и ситуации в контроле знакомы модели, формулировки новые.

**Повторение.** Установите зависимости по инструкции каталога выше. В v2 запустите `python ../run.py`, затем `python compare.py /путь/к/адаптеру_v1`. Чат: `python ../run.py --chat` из каталога v2. Полученный адаптер лежит в result/adapter.
